# Rare Friend Duel

**Builder:** @KingsCritket  
**Category:** Character Spotlight + Token Activity  

**One sentence:**  
A simple mobile-friendly 1v1 battle game where you fight using your own Rare Friend against an AI opponent, with simulated $RAREFRIENDS items.

## How it uses Rare Friends
- Player uses their own hardwired Generations Friend as the main character.
- Friend artwork is intended to be loaded from FriendSDK.
- Simulated RF can be spent on Potion and Damage Boost.

## Source
This repository contains the game files.

## How to run
This is a simplified version designed for easy submission.  
It is intended to work with FriendSDK v0.1.2.

## Controls
- Attack
- Defend  
- Special Ability
- Buy Potion (20 simulated RF)
- Buy Damage Boost (30 simulated RF)

## Notes
- All RF purchases are **SIMULATED**.
- No real transactions are made.
- Built for mobile.
